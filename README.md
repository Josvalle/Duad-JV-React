# Nombre del proyecto

Aplicación web creada con React + Vite para mostrar tres vistas: Inicio, Productos y Detalles.

## Requisitos

- Node.js instalado
- npm instalado

## Instalación

Clonar el repositorio:

git clone https://github.com/Josvalle/Duad-JV-React.git

## Correr el proyecto

npm install
npm run dev
